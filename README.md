# 📱 Yuzi Phone 玉子手机

SillyTavern 独立手机扩展，提供手机主屏、QQ 实时聊天、通用表格、Theater 小剧场、世界书工作台与设置管理能力。

## 功能

- 📱 手机容器：支持悬浮显示、拖拽移动、缩放与位置记忆
- 🏠 主屏与 App：提供主屏入口、表格查看与设置页面
- 💬 QQ：独立会话、联系人和消息存储，使用用户配置的 OpenAI 兼容接口
- 🔐 API 预设：QQ 密钥不以明文字段保存在常规预设记录中
- 📚 世界书工作台：选择手机系统读取的世界书和条目
- 🖼️ QQ 媒体消息：图片、语音、表情和转账属于 QQ 自己的数据模型
- 🎨 表格与场景美化：通用表模板与 Theater scene 各自渲染
- ⚙️ 数据与设置：支持数据库表格、外观和独立本地存储

## 开发与发布

本扩展是 SillyTavern 原生第三方扩展，`manifest.json` 实际加载 `dist/yuzi-phone.bundle.js` 与 `dist/yuzi-phone.bundle.css`。源码入口是 `index.js` 与 `style.css`，构建规则见 `BUILD.md`。

发布前必须执行：

```cmd
npm run lint
npm run check:ci
npm run build
```

`check:ci` 与 `check` 运行同一套检查，只额外防止没有发现检查脚本时空跑成功；发布流程运行一次 `check:ci` 即可。

`dist/` 必须提交；SillyTavern `auto_update` 只拉取仓库内容，不会替用户执行构建。表格模板事实源位于 `tables/sources/`，正式表源为 `小剧场2.1` 与 `纪要`，`恋爱特化参考` 是参考源；修改表源时，先用 `tables:build` 更新 `tables/generated/`，再运行 `tables:check` 校验，随后执行上述检查与构建。

脚本版 loader 互斥与 `window.__YUZI_PHONE_INSTANCE__` singleton guard 由 `scripts/check-script-loader-contract.cjs` 检查；版本字段由 `scripts/check-extension-version-contract.cjs` 检查；表源边界由 `scripts/check-table-sources-contract.cjs` 检查。release/dist 交付通过构建、CI 的产物与提交状态检查，以及发布前人工验收确认。

## 正文对话气泡

在小手机 **设置 → 正文对话气泡** 开启（默认关闭）。基础对白为 `「对白」`，头像或朗读开启时使用 `「姓名|对白」`。默认仅美化最近一条已完成的 AI 回复，不修改保存的聊天原文；流式期间显示原文。总开关关闭会恢复普通显示并删除受管的世界书条目。

提示词可分段编辑，点击保存后同步到当前角色卡主世界书，固定蓝灯、D0、顺序 999；实际注入预览只读，下方单独显示同步结果。没有主世界书不会擅自新建或选择附加书。

双语模式默认关闭；开启后将相邻的 `「原文台词」` 与 `「姓名|中文翻译」` 合为一条，上方以约正文一半的字号显示原文，下方正常显示译文；头像和朗读都关闭时可省略姓名。兼容普通换行与相邻普通段落，不跨旁白、代码或组件配对，落单对白保持单条显示。默认提示词要求先输出自然连贯的日语原文，再翻译成中文，中文采用动漫汉化组翻译风格；用户可自行修改语言，识别器不检测语言、不调用翻译服务。

朗读区的“朗读双语”默认关闭，开启仅朗读上方原文，关闭读下方译文；双语关闭时该选项置灰。姓名和音色仍取译文对应人物，切换停止当前播放，缓存按实际朗读文本区分。双语开启时，默认语气提示词与示例只在第一行原文添加声音标记，中文译文不添加，不随朗读来源切换；双语关闭时仍在普通对白中添加。内置姓名／语气示例随模式切换，改过的自定义提示词不自动改写；双语原文和译文都隐藏已知语气标记，合成保留所选台词的标记，不跨语言搬运标签。

正文朗读下的“语速与表现力”“标点表达”默认关闭，分别提供可编辑提示词、恢复默认和保存；总开关或正文朗读关闭时不注入。语速与表现力开启后使用 `「姓名|对白|语速,表现力」`，例如 `「小玉|你终于来了……|1,0.7」`；双语只在第二行译文后追加参数，朗读原文／译文共用。语速范围 0.5～2（正常为 1），表现力对应 Fish `temperature`、范围 0～1（默认 0.7）；缺失或无效数值回退默认，参数隐藏并单独传入 Fish，不会被朗读。关闭后仍能美化已有三段式对白，但不应用其参数，旧两段式对白继续兼容。音频缓存包含实际语速和表现力，开关切换停止旧播放，不重建正文。

“标点表达”仅要求后续对白按语境使用标点，不改写历史台词，也不把波浪号视为固定的音频拖音命令。语气标记的新默认说明允许按情节在对白前中后插入声音标记；原有 25 种清单和显示隐藏规则不变。未手改的旧默认文案自动更新；自定义提示词保留，可用“恢复默认”取得新版。

人物编辑在音色下方提供手填“语言”，留空或填写“默认”即跟随双语模块。总开关与双语开启、且头像或朗读至少开启一项时，只将当前角色卡中非默认的人物语言要求追加到语气标记之前；保存、改名、删除和清空语言会更新同一世界书条目，单改图片或音色不额外同步提示词。语言设置不替换人物音色、不重新翻译旧对白。内置“双语＋姓名”默认注入合为一段；任一段被手改时保留各自原文。

人物按角色卡隔离、手动创建；头像可裁剪上传，其余装饰与音色从现有仓库选择。正文保存独立副本，不反向修改 QQ。朗读使用设置 → TTS 的当前连接，默认点击才合成，音频在浏览器中按每个聊天的渲染窗口保留。语气标记只在总开关、朗读与语气标记都开启时加入提示词，展示隐藏已知标记，合成保留原有标记。

正文朗读区在“朗读双语”上方提供默认关闭的“语音预生成”：开启后补齐当前最新已完成楼层，此后新回复或重 roll 完成、美化后按阅读顺序逐条准备最新一楼的语音，不回扫历史楼层、不自动播放。原文／译文、音色、声音标记和语速／表现力与手动播放共用同一合成及缓存入口；已有缓存、未配置音色的人物跳过。仅正在预生成的对白按钮显示圆圈，结束后恢复播放键；点击圆圈共用正在进行的请求，完成后播放。普通单句失败写日志、跳过并继续下一句，当前楼层的失败记录仅保存在内存中，外观重绘不会自动重试，用户可手动点击重试；鉴权、限流、连接或服务不可用等错误停止这一批。关闭开关停止后台任务，用户已点击接管的请求继续；切换聊天、重 roll、修改朗读来源或连接时取消旧任务。已生成音频仍按原有渲染窗口清理，开关不改变世界书提示词。

“语音预生成”和“朗读双语”之间提供默认关闭的“重roll”。开启后，仅当前朗读版本已有缓存的对白在播放键旁显示旋转按钮，气泡与引号展示共用；手动生成或预生成成功后即可出现。点击使用当前文本、音色与朗读参数重新合成，停止当前正文播放，成功覆盖旧缓存并立即播放，失败保留旧缓存并沿用现有提示和日志。只替换当前选择的原文／译文版本，生成期间禁用旋转按钮；关闭重roll只隐藏入口，不取消已发起的请求，也不改变提示词。设置页样例不调用语音服务。

纯外观调整直接更新保留的气泡，不再触发正文扫描、完整性检查或语音任务组装。同一楼层按素材共用图片读取和临时 URL，楼层销毁统一释放，不建立全局图片缓存。预生成每批只读取一次 TTS 连接；普通 QQ 消息更新不触发正文连接检查，TTS 预设、参数或密钥实际变更时才通知。正文总开关关闭期间不扫描正文或检查 TTS，仍处理聊天／角色删除和缩小缓存窗口，重新开启后再校验当前渲染窗口。

人物图片与音频在本浏览器的独立 IndexedDB 中保存，清除网站数据会清除这些资料；它们不会写入角色卡或随聊天文件导出。

人物管理提供“导出全部人物配置”，将当前角色卡的全部人物保存为一个 JSON 文件：包含姓名、语言、头像、头像框、气泡的实际图片及校准参数，音色仅包含 ID 与名字。不包含角色卡绑定、聊天、已生成音频、提示词、总开关、TTS 连接或密钥。单张图片最多 8MB、配置包最多 64MB。

“导入人物配置”写入当前角色卡，默认保留本地同名人物；可在确认弹层开启“覆盖同名人物”，替换其整套配置，其他人物不受影响。空素材位保持为空，不随机补齐；图片独立保存，不要求接收方拥有原 QQ 素材，也不反向写入 QQ 或音色仓库。导入的音色 ID 直接用于正文朗读，但接收方仍需自行配置能使用该 ID 的 TTS 连接。整包校验后一次保存，失败不留下半套人物；成功后集中刷新，人物语言依照既有开关规则同步世界书。

## 安装说明

### URL 安装

1. 打开 SillyTavern
2. 进入“扩展” → “安装扩展”
3. 输入仓库地址：`https://github.com/yuzi52/st-yuzi-phone`
4. 安装后重启 SillyTavern

### 手动安装

1. 下载项目压缩包或最新 Release
2. 解压到 `SillyTavern/public/scripts/extensions/third-party/st-yuzi-phone`
3. 重启 SillyTavern
